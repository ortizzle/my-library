GitHub Gist Sync

Auto-saves your library to a private GitHub Gist after every change — versioned, accessible from any browser, free.

Create a token at GitHub → Settings → Tokens with the gist scope, then paste it below.

Google Books API Key

Optional. Book lookups work without it, but Google's free quota is shared across everyone on your network — on mobile data that runs out constantly and lookups fail with a rate-limit error. A key gives you your own quota (~1,000 lookups a day, free).

Get one at console.cloud.google.com — create a project, enable the Books API, then create an API key. Stored only in this browser.

Anthropic API Key

Stored only in this browser's localStorage. Sent only to Anthropic's API for AI discussion questions.

To check your credit balance, visit console.anthropic.com → Billing.

Export My Library

JSON preserves everything. CSV opens cleanly in Excel — one row per book.

On your phone, Export JSON opens the share sheet — choose Drive to pick the folder it's saved in. Each backup is named with the date.

Import & Reset

Your data is stored in this browser's localStorage under permanent keys — it will not be lost when you update this file.
